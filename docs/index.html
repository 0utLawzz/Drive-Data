DRIVE FOLDERS PATTERN MATCHER

A high-performance directory auditing desktop app designed for trademark legal teams. Scans cloud-mirrored structures locally, processes regex-matching rules dynamically, and updates Google Sheets with boolean statuses.

20 Active Rules Google Sheets Sync Local Excel/CSV Export Incremental Renames

🚀 Core Capabilities

🔍 Scanning Engines

Choose the optimal scan strategy depending on the folder complexity:

  • Deep Scan (Thorough): Traverses all folder levels recursively using os.walk to capture loose files.
  • Fast Scan (Strict): Audits exact 2-level depths (Clients ➔ Cases) for lightning-fast speeds over networks.

⚙️ Dynamic Rules Manager

Edit case triggers and column outputs instantly in the GUI without touching Python code:

  • Seeded with 14 default trademark categories (TM-1, TM-48, OPPO, NTN).
  • Add custom matching patterns using regex strings.
  • Redirect rules to merge into existing columns or output to new ones.

📊 Smart Integrations

Fully formatted and protected outputs:

  • Google Sheets Sync: Automatic columns check and sync + frozen headers, bold text, and column width autofitting.
  • File Overwrite Protection: Local exports auto-increment file names (e.g. all_patterns_1.xlsx) instead of replacing.

💻 Setup & Run

Installation

1. Clone the repository and install dependencies:

git clone https://github.com/0utLawzz/Drive-Data.git
cd Drive-Data
pip install -r requirements.txt

2. Download Google Cloud service account keys to credentials.json inside the root directory.

3. Run the application via the desktop launcher or terminal:

# Windows Launcher
run.bat

# Python Command
python main.py
